# 🤖 JARVIS - Python Voice Assistant

A desktop-based intelligent voice assistant built using Python that supports voice commands, GUI interaction, and web integration.

## 🚀 Features
- 🎙️ Voice command recognition
- 🔊 Text-to-speech responses
- 🎵 Play music from YouTube
- 🌐 Open websites and perform web searches
- 📰 Fetch latest news
- 🌦️ Weather updates
- 💻 GUI interface for interaction
- 🤖 AI-powered Q&A (using APIs like Cohere)

## 🛠️ Tech Stack
- Python
- Tkinter (GUI)
- SpeechRecognition
- pyttsx3 (Text-to-Speech)
- Flask (for backend integration)
- pywhatkit (YouTube automation)
- APIs (Weather, News, AI)

## Setup
pip install -r requirements.txt
<br>
python main.py

## Requirements
- Python 3.x
- Flask
- pyttsx3
- SpeechRecognition
- pywhatkit

## 🎯 How It Works
* The system listens to user voice input.
* Converts speech to text using SpeechRecognition.
* Processes command logic.
* Responds via voice using pyttsx3.
* Executes tasks like opening apps, playing music, or fetching data.
